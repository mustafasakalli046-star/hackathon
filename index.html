Uygulanan Güvenlik Önlemleri

✓ Parola Hashing (SHA-256 + Salt)

Parolalar asla düz metin saklanmaz. Üretimde bcrypt/argon2 önerilir.

✓ SQL Injection Koruması

Üretimde SQLAlchemy ORM + parametreli sorgular. Ham SQL yasak.

✓ XSS Sanitizasyonu

Tüm girdiler escape edilir, script etiketleri temizlenir.

✓ Rate Limiting + Lockout

5 hatalı girişte 5 dk kilit. Formda saatlik 3 gönderim limiti.

✓ Oturum & JWT Süre Sonu

2 saatlik token ömrü, her istekte doğrulama, güvenli çıkış.

✓ Honeypot + Doğrulama

Bot tuzağı alanı, e-posta/telefon regex, mükerrer kayıt engeli.
